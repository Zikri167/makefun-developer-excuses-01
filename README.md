This entry writes one funny single-line excuse a developer gives when code breaks in production: a developer proudly fixes a typo, only to discover in the last words that the typo itself was load-bearing — the one thing keeping production alive. It is deterministic, uses only the Node standard library, and writes the line to `entry.txt`.

## Run it

```sh
node main.ts
```
